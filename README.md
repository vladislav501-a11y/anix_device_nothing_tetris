# Anix OS (OFFICIAL) for CMF Phone 1 (tetris)
**Maintained by #archsu**

Anix OS is a performance and aesthetic focused Android distribution based on Evolution X with iOS-inspired Control Center, frosted glass blur, and custom branding.

### Device Specifications
* **Device**: CMF Phone 1 by Nothing
* **Codename**: `tetris`
* **SoC**: MediaTek Dimensity 7300
* **Kernel**: Linux 6.1

### Features
* Official build type
* GApps included
* iOS Style Split Notification & Control Center
* Custom Anix OS bootanimation & default Liquid Glass wallpaper
* Maintainer: `#archsu`
